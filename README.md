# sonicwave audio - sistema de gestion de licencias y suscripciones

## descripcion del proyecto

este repositorio contiene la documentacion tecnica del proyecto de software desarrollado para sonicwave audio, una empresa ficticia de plugins y hardware de audio profesional. el sistema propuesto automatiza la activacion, renovacion y control de licencias y suscripciones de los plugins de la empresa.

trabajo practico integrador - organizacion empresarial - tecnicatura universitaria en programacion (utn)
