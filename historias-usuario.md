# historias de usuario - sistema de gestion de licencias y suscripciones

## hu-01
como usuario quiero iniciar sesion en el sistema
para poder acceder a mis licencias y funcionalidades segun mi rol.
estado: listo

## hu-02
como cliente quiero activar la licencia de un plugin
para poder utilizar el software que adquiri sin demoras.
estado: en progreso

## hu-03
como cliente quiero recibir notificaciones sobre el vencimiento de mi suscripcion
para poder renovarla a tiempo y no perder el acceso al plugin.
estado: por hacer
